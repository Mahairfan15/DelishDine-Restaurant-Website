# 🍽️ DelishDine Restaurant Website

Welcome to **DelishDine** — a beautifully designed, responsive restaurant website created to showcase delicious meals with smooth animations, elegant typography, and an interactive "Order Now" feature.  

This project highlights modern web design using **HTML**, **CSS**, and **Bootstrap**, with a touch of creativity and attention to detail.

---

## ✨ Features

- 🏠 **Hero Section** with background image and glowing title  
- 🍛 **Interactive Food Categories** — Rice Items, Fried Items, Desserts  
- 💫 **Smooth Hover Animations** and modern UI design  
- 📱 **Fully Responsive Layout** (works perfectly on mobile, tablet, and desktop)  
- 🖋️ **Google Fonts** for clean and elegant typography  
- 🛒 **“Order Now” Section** with a simple contact form  
- 🎨 **Custom CSS Effects** with shadows, transitions, and gradient backgrounds
